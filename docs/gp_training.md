# GP（高斯过程）模型的训练原理

本文说明 `trim_bo.py` 中的高斯过程（GP）代理模型是如何用历史数据训练的。

3 个配方（频率/功率/脉宽固定搭配）**各训练一个独立的 GP**，每个 GP 的输入是 $\log_{10}$ 目标阻值和修阻速度，输出是分数：

$$
\text{分数} = 0.5 \times \text{良率} - 1 \times \text{FT SD}
$$

以下以其中一个配方约 460 条数据为例。

> 公式使用 LaTeX 写法，在 GitHub、VS Code 等 Markdown 查看器中会渲染成数学公式。

---

## 1. 训练之前：数据预处理

| 步骤 | 做法 | 目的 |
|---|---|---|
| 清洗 | 转成浮点数，去掉缺失值、配方未知或速度超出 `VALID_SPEED` 的行；**保留**重复实验 | 重复实验能反映噪声大小 |
| 输入归一化 | 目标阻值先取 $\log_{10}$（跨 7 个数量级），再和速度一起换算到 $[0, 1]$ | 两个变量尺度一致，可以公平比较 |
| 输出标准化 | 分数换算成均值 0、标准差 1 | 超参数不受分数量级影响 |

---

## 2. 原理：GP 对未知函数做了什么假设

### 2.1 核心假设

分数与参数之间的真实关系 $f(x)$ 是未知的。GP 不假设它是某个具体公式（例如二次函数），而是假设：

> **任意几组参数下的真实分数，合在一起服从一个多元正态分布。**

这个分布由两部分决定：

- **均值**：常数 $\beta$，即整体平均水平（`trend.constant_trend`）；
- **协方差**：两组参数的分数有多相关，由核函数决定：

$$
\mathrm{Cov}\big(f(x_i),\, f(x_j)\big) = \sigma^2 \, r(x_i, x_j)
$$

其中 $\sigma^2$ 是真实分数的起伏幅度，$r \in [0, 1]$ 是相关系数。

### 2.2 核函数（Matern，$\nu = 1.5$）

先计算两组参数之间的"有效距离"：

$$
d = \sqrt{\theta_{\text{阻值}} \, (\Delta \log_{10}\text{阻值})^2 + \theta_{\text{速度}} \, (\Delta \text{速度})^2}
$$

再由距离得到相关系数：

$$
r = \left(1 + \sqrt{3}\, d\right) e^{-\sqrt{3}\, d}
$$

- $d = 0$（同一组参数）时 $r = 1$，完全相关；
- $d$ 越大，$r$ 越接近 0，几乎无关；
- $\theta$ 越大，参数稍有变化 $d$ 就变大，说明分数对这个参数**越敏感**。影响范围（长度尺度）为 $\ell = 1/\sqrt{\theta}$。

### 2.3 加入测量噪声

实测分数 = 真实分数 + 噪声：

$$
y_i = f(x_i) + \varepsilon_i, \qquad \varepsilon_i \sim \mathcal{N}(0, \tau^2) \text{，各次实验相互独立}
$$

因此 $n$ 个实测分数的联合分布为：

$$
y \sim \mathcal{N}\big(\beta \mathbf{1},\; K\big), \qquad K = \sigma^2 R_0 + \tau^2 I
$$

其中 $R_0$ 是 $n \times n$ 的相关矩阵（第 $i$ 行第 $j$ 列为 $r(x_i, x_j)$），$I$ 是单位矩阵。

### 2.4 训练要确定什么

| 超参数 | 含义 |
|---|---|
| $\theta_{\text{阻值}}$、$\theta_{\text{速度}}$ | 分数对每个参数的敏感程度 |
| $\sigma^2$ | 真实分数的起伏幅度 |
| $\tau^2$ | 噪声大小 |
| $\beta$ | 平均水平 |

**训练 GP = 根据数据估计这几个超参数。** 与神经网络不同，这里没有成千上万个权重，每个配方只有这 5 个数。

### 2.5 估计方法：最大似然

对任意一组候选超参数，都能算出"恰好测到这些分数"的概率密度，即**似然**。训练就是寻找似然最大的超参数。对数似然为：

$$
\log L = -\frac{1}{2}\Big[
\underbrace{(y - \beta\mathbf{1})^\top K^{-1} (y - \beta\mathbf{1})}_{\text{拟合误差}}
+ \underbrace{\log |K|}_{\text{复杂度惩罚}}
+ n \log 2\pi
\Big]
$$

两项此消彼长：

- **拟合误差**：$\theta$ 越大，模型越灵活，越能贴合每个数据点，这一项越小；
- **复杂度惩罚**：模型越灵活（各点越独立），$\log|K|$ 越大。

两者的平衡点，就是**既能解释数据、又不过度拟合**的超参数，相当于自动实现了奥卡姆剃刀，因此不需要单独留验证集来防止过拟合。

噪声也是这样估计出来的：如果同一组参数的两次实验差了 3 分，没有噪声项的模型无法解释这个差异，似然会很低，最优解自然会包含合适大小的 $\tau^2$。

## 3. 过程：库中的具体计算步骤

`make_model` 的配置为 `likelihood="concentrated"`、`noise_estim=True`。

### 3.1 减少需要搜索的参数（concentrated likelihood）

1. 把噪声改写成比例：

$$
\alpha = \frac{\sigma^2}{\sigma^2 + \tau^2} \quad \text{（真实起伏占总波动的比例）}
$$

2. 归一化的相关矩阵：

$$
R = \alpha R_0 + (1 - \alpha) I
$$

3. 给定 $\theta$ 和 $\alpha$ 后，$\beta$ 和总方差有解析解：

$$
\hat{\beta} = \frac{\mathbf{1}^\top R^{-1} y}{\mathbf{1}^\top R^{-1} \mathbf{1}},
\qquad
\hat{\sigma}^2_{\text{总}} = \frac{(y - \hat\beta\mathbf{1})^\top R^{-1} (y - \hat\beta\mathbf{1})}{n}
$$

4. 代回似然，得到只依赖 $\theta$ 和 $\alpha$ 的浓缩似然：

$$
\log L(\theta, \alpha) = -\frac{1}{2}\Big[ n \log \hat{\sigma}^2_{\text{总}} + \log |R| \Big] + \text{常数}
$$

这样**需要数值搜索的只剩 3 个数**：$\theta_{\text{阻值}}$、$\theta_{\text{速度}}$、$\alpha$。

### 3.2 计算一次似然

对一组候选参数 $(\theta_{\text{阻值}}, \theta_{\text{速度}}, \alpha)$：

1. 构造相关矩阵 $R_0$，得到 $R$；
2. 对 $R$ 做 **Cholesky 分解** $R = L L^\top$。这是最耗时的一步，计算量约为 $n^3$；
3. 用 $L$ 求出 $R^{-1} y$ 和 $\log|R| = 2 \sum_i \log L_{ii}$，进而得到 $\hat\beta$、$\hat\sigma^2_{\text{总}}$ 和似然值；
4. 同时计算似然对 3 个参数的**梯度**，供优化算法使用。

如果 $R$ 数值上接近奇异，导致分解失败，这组参数直接判为不可行。

### 3.3 搜索最优超参数

| 设置 | 说明 |
|---|---|
| 搜索范围 | $\theta \in$ [`thetaL`, `thetaU`] $= [1, 10^{3}]$，$\alpha \in (0, 1)$。下限为 1 是为了避开"$\theta$ 极小、方差极大"的退化解，那种解的不确定度会虚高 |
| 搜索空间 | $\theta$ 横跨 3 个数量级，在 $\log_{10}$ 空间中搜索 |
| 算法 | L-BFGS-B（利用梯度、支持上下界）——`optimizer="BFGS"` |
| 多次重启 | 似然常有多个局部极大值，在范围内随机选起点，最多 `random_start` 次（30 次） |
| 提前停止 | 连续 `wait_iter`（10）次重启没有改进，或似然计算总次数用完 `eval_budget`（2000 次，各次重启共用） |
| 结果 | 所有重启中似然最大的那组参数 |

### 3.4 保存预测所需的中间量

找到最优参数后，模型保存：

- $R$ 的 Cholesky 因子 $L$；
- $\hat\beta$、$\hat\sigma^2$（信号部分）、$\hat\tau^2$（噪声部分）；
- $\gamma = R^{-1}(y - \hat\beta\mathbf{1})$：每个数据点对预测的贡献系数。

---

## 4. 训练完成后：预测

对任意新参数 $x$，先算它与每个数据点的相关系数，组成向量 $r(x)$，然后：

**预测均值**

$$
\mu(x) = \hat\beta + \alpha \, r(x)^\top \gamma
$$

即在平均水平上，按"与 $x$ 的相关程度"加权，参考各数据点比平均高或低多少。离 $x$ 越近的数据权重越大。由于考虑了噪声，预测曲线不会硬穿过每个数据点，而是在附近数据之间平滑折中。

**不确定度**

$$
s^2(x) = \hat\sigma^2_{\text{总}} \Big[ \alpha - \big\| L^{-1} \alpha\, r(x) \big\|^2 + \text{（均值估计的不确定性项）} \Big]
$$

- 附近数据多：$s$ 小，模型有把握；
- 附近没有数据：$s$ 大，预测回落到平均水平 $\hat\beta$。

> 公式中的 $\alpha$ 正是 `37b418e` 修复的 bug：原代码在预测时漏掉了 $\alpha$，导致有噪声时不确定度被算成 0。

单点预测的计算量只有 $n$～$n^2$，因此 EI 优化时调用成千上万次预测也很快。

```
分数
 ↑        ·  ·                     ← 实测点（有噪声）
 │     ·  ━━━━━  ·                 ← 预测均值 μ(x)：平滑穿过数据
 │   ·━━━      ━━━·
 │  ━━   ░░░░░░   ━━━━━━━          ░ 不确定度：数据密处窄
 │ ━   ░░        ░░░░░░░░░░░░░░    ← 右侧没数据：不确定度很宽
 └────────────────────────────→ 频率
```

---

## 5. 从模型到推荐：EI（期望改进）

设当前最好分数为 $f^*$（该目标阻值下，已测参数中**模型预测**的最高分），令 $z = (\mu(x) - f^*) / s(x)$，则：

$$
\mathrm{EI}(x) = \big(\mu(x) - f^*\big)\, \Phi(z) + s(x)\, \varphi(z)
$$

其中 $\Phi$、$\varphi$ 分别是标准正态分布的累积分布函数和密度函数。

- 第一项大：预测分数本身高，即在已知好区域附近挖掘；
- 第二项大：不确定度大，即去没试过的地方探索。

对给定的目标阻值，在 3 个配方 × 速度网格上计算 EI，最大的那组就是推荐的下一组实验。

> 注意：$f^*$ 不用实测最高分。实验有噪声时，实测最高分往往是偶然测高的，用它做基准会让推荐偏向没有数据的区域。

## 6. 数据量与计算量

| 配方 | 数据量 $n$ | 一次训练（真实数据） |
|---|---|---|
| 10 kHz | 454 | 约 7 s |
| 50 kHz | 458 | 约 5 s |
| 100 kHz | 463 | 约 6 s |

Cholesky 分解的计算量按 $n^3$ 增长，再乘以数百次搜索，因此把数据按配方拆开训练，比 1375 条合在一起快得多。

## 7. 总结

```
GP 假设：分数 ~ 多元正态(均值 β, 协方差 σ²·相关矩阵(θ) + 噪声 τ²)
                          │
训练 = 最大似然估计超参数
  ├─ β、总方差：解析公式直接算（concentrated）
  └─ θ阻值、θ速度、α：L-BFGS-B 在 log 空间搜索
        └─ 每一步：构造 R → Cholesky 分解 → 算似然和梯度
        └─ 最多 30 个随机起点，连续 10 次无改进或用完 2000 次就停
                          │
保存 L、β、γ 等中间量 → 预测任意点的 μ(x) 和 s(x)
                          │
EI 综合 μ 和 s → 推荐下一组实验 → 录入结果后重新训练
```
